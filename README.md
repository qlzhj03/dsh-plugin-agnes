# Agnes Studio for DSH

简体中文 · [English](README.en.md)

面向 [Agnes AI API](https://www.agnes-ai.cn/zh-Hans/docs/overview) 的 DSH（DeepSeekRuntime）Web 持久化插件。

- 只提供一个 `agnes_studio` 工具，统一完成文本、图片与视频生成。
- 生成结果（图片、视频、文本）直接在对话中渲染预览。
- 左侧边栏提供常驻的 **Agnes 作品** 页面，可浏览、下载和删除已生成的媒体。
- 需求模糊时直接使用对话底部的原生提问收集主体/用途，同时给出推荐比例/清晰度或时长/分辨率，不展示额外卡片，也不凭空生成。
- **设置 → Agnes Studio** 只包含模型连接与文本/图片/视频模型映射，复用 DSH 官方 **设置 → 模型** 的自定义供应商配置。
- 文本、图片、视频共用同一个 API Key。密钥保存为 DSH 凭据，不会进入浏览器 bundle 或生成的客户端代码。
- 生成的媒体会下载到当前 DSH profile 的 `agnes-studio/` 目录，并通过同源 Host 路由访问，不暴露文件系统路径。

## 安装

插件以 DSH profile bundle 的形式安装，需要 DSH Web 的 **插件** 页面或 `dsh plugin` 命令。

### 从 Git 仓库安装（推荐）

1. 在 DSH 侧边栏打开 **插件**，点 **添加插件** → **安装第三方插件**。
2. 填入仓库地址 `git+https://github.com/qlzhj03/dsh-plugin-agnes.git`，点 **安装**。
3. 安装完成后点 **立即启用**；如果提示需要重启，重启 DSH。
4. 打开 **设置 → Agnes Studio**，点 **创建 Agnes 供应商**，再到 **设置 → 模型 → Agnes** 填入 API Key。

也可以在终端执行：

```bash
dsh plugin --profile web add git+https://github.com/qlzhj03/dsh-plugin-agnes.git
```

然后重启 DSH。

### 从压缩包或本地目录安装

适合内网或离线分发。在插件目录执行：

```bash
pnpm pack
```

将生成的 `local-dsh-agnes-studio-1.0.0.tgz` 发给对方，对方在 **插件 → 添加插件 → 安装第三方插件** 中选择该压缩包，或填入它的绝对路径。开发者也可以直接填插件目录的绝对路径，以 `link:` 方式安装。

## 配置

首次使用时打开 **设置 → Agnes Studio**。如果尚无 Agnes 供应商，点击 **创建 Agnes 供应商**。该操作会在 DSH 的 **设置 → 模型** 页面创建一个名为 `agnes` 的自定义模型供应商：

| 字段 | 值 |
| --- | --- |
| Base URL | `https://api.agnes-ai.cn/v1` |
| API 协议 | OpenAI Chat Completions |
| 凭据引用 | `AGNES_API_KEY` |
| 模型 | `agnes-3.0-flash` |
| 上下文窗口 | `512000` |
| 最大输出 | `65536` |

供应商目录只登记文本模型，这样 DSH 的模型选择器中会出现可用的对话模型；图片与视频模型 ID 则保留在下面的 Agnes Studio 模型映射中。

然后打开 **设置 → 模型 → Agnes**，粘贴 Agnes 平台控制台中的 API Key。文本、图片、视频共用这一把 Key，Agnes Studio 页面不单独提供 Key 输入框。若 Host 环境变量中存在 `AGNES_API_KEY` 且没有已保存的凭据，插件也会使用它。

**设置 → Agnes Studio** 中的模型映射默认值：

| 设置项 | 默认值 |
| --- | --- |
| 文本模型 | `agnes-3.0-flash` |
| 图片模型 | `agnes-image-2.5-flash` |
| 视频模型 | `agnes-video-2.5-flash` |

模型下拉列表从当前供应商的 `/models` 接口实时获取，并按模型 ID 自动归类为文本、图片和视频；当前值不在列表中时仍会保留，避免保存时丢失配置。供应商本身在 DSH **设置 → 模型** 中管理，插件页面不再提供供应商下拉框。API Key 与 Base URL 在插件页面中刻意保持只读。

## 在对话中使用

直接用自然语言描述即可，例如：

- “生成一张 16:9 的雨夜未来城市海报。”
- “帮我画一张图。”或“做段视频。”：插件会直接用底部原生提问询问画面主体/用途，并给出推荐规格。
- “生成一段 5 秒的视频：雨后霓虹街道，银色跑车驶过。”
- “用 Agnes 写一段产品发布会开场文案。”
- “看看我之前生成的图片。”

插件会向模型注入使用指引，图片与视频请求会自动调用 `agnes_studio`，无需打开设置或点名工具。普通对话仍交给助手处理；只有当你明确要求用 Agnes 做文本生成时，才会走 Agnes 文本能力。结果直接渲染在对话里，并保存到左侧边栏的 **Agnes 作品** 页面。

### 模糊需求

当请求只有形式、风格或用途，没有具体画面主体时（例如“画个图”“做张海报”“来段视频”），工具不会猜一个画面直接生成，也不会展示额外卡片；它会通过对话底部的原生提问询问主体/用途：

- 图片：推荐方形 1:1、竖版 3:4、横版 16:9、手机竖屏 9:16，默认 2K。
- 视频：推荐竖屏 9:16、横屏 16:9、方形 1:1；默认 5 秒，预览 720P、横屏成片 1080P。

推荐规格会随问题一起给出；回复主体和用途，或直接说“按推荐生成”即可继续。若主体已经明确，只是没写比例、清晰度、时长等参数，插件会按用途选择合适规格直接生成，并在结果中注明所用参数。

## 存储

当 Host 暴露 `DSH_PROFILE_DIR` 时，历史与媒体位于 `$DSH_PROFILE_DIR/agnes-studio/`，否则位于 `~/.dsh/agnes-studio/`。历史记录文件最多保留最新 500 条。
